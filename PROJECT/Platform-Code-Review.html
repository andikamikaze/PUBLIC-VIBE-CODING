Fix token refresh race condition #482

api-gateway · maya-chen · Updated 12 minutes ago

HIGH

Refresh token can be reused concurrently

src/auth/refresh.ts:84

Two simultaneous requests can both pass the token validity check before either rotation completes. This creates a window where the old refresh token remains usable and can issue multiple access tokens.

- const session = await getSession(token)
+ const session = await rotateTokenAtomically(token)
if (!session) return unauthorized()
MEDIUM

Missing rate limit on refresh endpoint

src/auth/refresh.ts:52

The refresh endpoint does not apply the shared auth rate limiter. Repeated requests may increase database load and make token abuse easier.

LOW

Token rotation event is not logged

src/auth/refresh.ts:91

Consider recording successful and rejected rotation attempts to improve incident investigation without logging token values.
