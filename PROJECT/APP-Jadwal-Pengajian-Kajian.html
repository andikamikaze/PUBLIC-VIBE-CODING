Manajemen Pendaftaran

Pendaftaran Saya

Kapasitas tempat terbatas? Amankan kursi Anda dengan mendaftar. Data tersimpan di perangkat ini dan pengingat otomatis diaktifkan.

1
Pilih Kajian

Buka halaman Jadwal, lalu pilih kajian rutin atau akbar yang ingin Anda ikuti.

2
Daftar Hadir

Isi nama & nomor WhatsApp. Bila kapasitas penuh, Anda otomatis masuk waiting list.

3
Dapatkan Pengingat

Notifikasi sebelum kajian dimulai, ditambah file kalender (.ics) untuk HP Anda.

Tiket & Pengingat Saya

Daftar hadir Anda pada perangkat ini. Panitia memverifikasi kehadiran berdasar data ini.

Pemateri

Profil Ustadz & Penceramah

Kenali lebih dekat para pemateri yang mengisi kajian — riwayat pendidikan, bidang keahlian, serta kajian dan materi yang mereka ampu.

ℹ️ Profil ustadz dikelola melalui Panel Admin → tab Ustadz.

Arsip Digital

Arsip Materi Ceramah

Unduh materi kajian berupa modul PDF atau rekaman audio MP3 untuk dipelajari kembali di rumah.

🔍

ℹ️ Materi dikelola melalui Panel Admin → tab Materi. Tombol unduh menghasilkan file ringkasan (simulasi) — sambungkan dengan tautan berkas asli milik masjid Anda.

Khusus Pengurus

Panel Admin

Kelola jadwal kajian, pendaftar jamaah, profil ustadz, arsip materi, rekaman video, dan siaran live dari satu tempat.

🔐

Masuk Panel Admin

Masukkan kata sandi pengurus untuk mengelola konten aplikasi.

Kata sandi awal: admin123 — segera ubah di tab Pengaturan setelah masuk.
