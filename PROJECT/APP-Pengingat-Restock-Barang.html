Tentang & Cara Pakai

SiagaStok adalah aplikasi pengingat restock barang yang berjalan dari satu berkas HTML tanpa instalasi. Semua data disimpan di localStorage browser Anda — tidak ada data yang dikirim ke internet.

Cara pakai singkat
  1. Tambahkan barang beserta batas minimal stok pada menu Inventori.
  2. Catat setiap stok masuk / keluar — status hijau, kuning, merah dan riwayat diperbarui otomatis.
  3. Saat stok menyentuh batas minimal, pengingat otomatis masuk ke Pusat Notifikasi (dan notifikasi browser bila izinkan).
  4. Buka Quick Reorder untuk menyusun daftar belanja per supplier, lalu salin, email, atau cetak.
  5. Saat barang tiba, gunakan Terima Barang untuk mencatat stok masuk sekaligus dari satu pesanan.
Aturan warna status stok

Merah stok ≤ batas minimal (kritis / habis)    Kuning stok ≤ 2× batas minimal (menipis)    Hijau stok di atas 2× batas minimal (aman).

Catatan teknis

Notifikasi browser memerlukan izin dan hanya aktif selama halaman terbuka. Web push sungguhan membutuhkan service worker dan server push — di luar cakupan berkas HTML tunggal. Email pengingat ditampilkan sebagai pratinjau otomatis; pengiriman email sungguhan memerlukan layanan email server. Kedua batasan ini dijelaskan agar transparan.
