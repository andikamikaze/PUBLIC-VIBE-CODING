Tentang Aplikasi

Buku Utang v1.0 — aplikasi pencatatan utang piutang pribadi. Seluruh data tersimpan lokal di browser Anda (localStorage) dan tidak pernah dikirim ke server mana pun.

Klik "Tambah" untuk mencatat utang atau piutang baru

Gunakan tombol "Bayar" untuk mencatat pembayaran parsial atau cicilan
