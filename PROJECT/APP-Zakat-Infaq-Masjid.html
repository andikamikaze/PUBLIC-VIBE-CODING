Ringkasan Pembayaran

Ke Mana Dana Disalurkan?

Zakat disalurkan kepada 8 golongan asnaf: Fakir, Miskin, Amil, Muallaf, Riqab, Gharim, Fisabilillah, dan Ibnu Sabil (QS At-Taubah: 60). Infaq & shadaqah digunakan untuk operasional masjid dan program sosial jamaah.

Tentang Aplikasi

ZIS Masjid v1.0 — aplikasi satu berkas HTML untuk pengelolaan Zakat, Infaq & Shadaqah masjid.
  • Kalkulator zakat maal, profesi, dan fitrah dengan perhitungan otomatis
  • Formulir pembayaran / donasi dengan QRIS, Virtual Account, dan tunai (simulasi)
  • Buku kas digital masuk-keluar yang transparan untuk jamaah
  • Manajemen data mustahik 8 asnaf dengan verifikasi
  • Cetak / unduh e-bukti transaksi dan laporan bulanan (PDF & CSV)
Aplikasi ini bersifat demo offline-first: seluruh data tersimpan di browser (localStorage) dan alur pembayaran disimulasikan. Untuk penggunaan daring dengan pembayaran nyata, integrasikan payment gateway dan server database.
— Aplikasi Zakat, Infaq & Shadaqah. Dikelola oleh DKM untuk transparansi pengelolaan dana jamaah. Data tersimpan lokal di perangkat Anda.
